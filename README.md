# Netflix Content Analysis | Power BI

## Project Overview

This project analyses Netflix's content catalogue using Power BI to identify trends in content type, release years, ratings, countries, and directors. The interactive dashboard provides a consolidated view of Netflix's movies and TV shows.

## Objectives

- Analyse the distribution of Movies and TV Shows
- Identify content trends by release year
- Analyse content ratings
- Examine Netflix content distribution across countries
- Compare directors across content types
- Identify key patterns in Netflix's content catalogue

## Dashboard

### Netflix Content Insights

The dashboard provides:

- Total Shows
- Movies vs TV Shows
- Content trends by release year
- Directors by content type
- Content distribution by rating
- Geographic distribution of Netflix content

## Key Metrics

- Total Shows: 7,971
- Movies: 5,687
- TV Shows: 2,284

## Key Features

- Interactive filters for Show Type, Release Year, and Country
- KPI cards for high-level content metrics

- Rating and country-level analysis
